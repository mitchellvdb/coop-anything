DDCoop test82 / solo duo61 - automatic logs collected on the host

Close game windows before installing. Host installs test82; friends on test77
or newer can accept its signed update when joining. Everyone uses the same kit.

1. Host/join normally with 2-4 players. While connected, any player clicks Copy
   logs. Their launchers collect the selected diagnostic files automatically.
   Keep every launcher open while the host's button shows Logs <received>/<players>.
2. On the HOST desktop, look for DDCoop-report-<time>-<id>.zip. It contains a
   host folder and player-2/3/4 folders. REPORT.txt lists received, failed or
   missing players; FILES.txt lists missing or truncated individual files.
   Send only this combined ZIP; guests no longer need to send separate folders.
3. A newly detected in-game desync automatically triggers the same collection.
   Resync and session failures also collect logs. The game may close and guest
   backups may recover while delivery finishes; leave launchers open for up to
   two minutes. A lost connection cannot deliver logs; missing players are shown.
4. Confirm that the ZIP includes the actual host and guest runtime logs and both
   launchers' logs. It must not contain campaign saves or ddcoop.ini. Known
   authentication/password lines are filtered. Reports stay private on the host.
5. Retest normal resync and guest backup recovery. Neither should require waiting
   for diagnostic completion. The host can leave the screen idle while guests act.
6. Retest inventory-full OK from a guest, loot, mixed-owner combat, Tavern/Abbey,
   learned/active skills and Stagecoach after a raid. Existing gameplay is test81;
   this kit changes diagnostic collection and the matching runtime version label.

Solo duo61: its single launcher collects all locally present runtime logs, so
there are no separate guest launchers to upload. Install the duo kit manually,
Host, then use the included second/third/fourth-window batch files. Do not mix
normal/duo variants. Solo batch guests still restart manually after resync.

Logs use bounded tails (runtime2MiB/file, other512KiB/file), with truncation and
missing files listed explicitly. They can still contain names and paths; do not
post reports publicly. Live multi-PC diagnostic transfer needs this owner test.
